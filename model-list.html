模型列表与价格比对

汇总不同账号和 API 凭据中的模型、价格与可用性信息，方便你按实际使用场景筛选和比较，再选择合适的模型与来源。

功能概览

  • 💰 跨账号价格比较：把不同账号和 API 凭据中的同一模型放在一起，按统一口径比较价格。
  • 🎯 贴近用量的估算：可选择普通对话、代码补全、编码 Agent 等使用场景，也可以自行调整输入、输出和缓存占比。
  • 🔍 多维深度过滤：支持按站点来源、API 凭据、提供商（OpenAI, Anthropic 等）、计费方式和标签进行组合筛选。
  • ✅ 批量可用性验证：支持模型连通性测试、Token 兼容性检测以及 CLI 代理可用性验证。
  • 📊 计费透明化：清晰区分“按量计费（Tokens）”与“按次计费（Per Call）”，并展示输入、输出和缓存的实际单价。

进入方式

  1. 在扩展弹窗中点击左下角的 “模型列表” 图标。
  2. 或在 设置 → 模型管理 中进入。

核心操作指南

1. 选择数据源

在页面顶部的选择器中，你可以切换不同的数据源：

  • 全部账号：聚合你已添加的所有站点账号，开启跨站比对。
  • 特定账号：查看指定站点的完整模型目录。
  • API 凭据：查看 API 凭据库中已保存 Key 支持的模型（无需创建站点账号）。

2. 比较价格

需要跨账号比价时，点击 “比较价格”。页面会切换到全部账号，并优先排列同一模型中价格较低的报价。

  • 设置比较条件：选择与你用途接近的使用场景，或自行调整输入、输出、缓存读取和缓存写入占比。
  • 查看可比较报价：只有计费方式相同、且能提供当前比较条件所需价格数据的报价会参与排名。其他报价仍会显示在“未参与当前条件比较”中，方便你检查缺少了哪项价格。
  • 核对价格明细：按量计费的模型会显示每 100 万 Token 的输入、输出和缓存价格；按次计费的模型会显示每次调用价格。展开模型还可以查看各分组价格。

价格标签可以这样理解：

  • 估算价：根据现有价目和分组信息计算，适合用于筛选；实际账单仍以服务方为准。
  • 最低价：当前筛选与比较条件下，可比较报价中的最低选项。
  • 最优组：可比较分组中只有一个分组价格最低时显示；如果最低价并列，则不会指定其中一个。

3. 分组切换与模拟

如果一个站点支持多个用户分组（如 default、vip、svip），你可以在筛选栏中限定参与比较的分组，并展开模型查看各分组的价格。

💡 技巧：分组会直接影响实际单价。准备使用某个报价前，请确认账号确实可以使用对应分组。

4. 模型验证

点击模型卡片右侧的验证图标：

  • 验证模型：发送一个轻量级请求，确认该模型当前是否真实可用。
  • 验证 CLI 兼容性：测试该模型是否支持流式输出，以及是否能被命令行工具正常调用。
  • 批量验证：点击工具栏的 “批量验证” 为当前过滤出的所有模型排队执行测试。你也可以通过复选框勾选特定的模型，仅对选中的部分进行批量验证。

列表控制项

配置项说明
搜索框支持模型 ID（如 gpt-4o）或站点名称模糊搜索。
计费模式可筛选“按量计费”或“按次计费”的模型。
提供商筛选快速锁定 OpenAI、Anthropic、Google、Meta 等厂商的模型。
排序方式可使用默认顺序、同模型最低价优先、价格升降序或验证耗时排序。
价格比较条件在价格排序下选择使用场景，或自行调整输入、输出和缓存占比。
显示设置可控制是否显示人民币价格和服务端类型。

常见问题

问题解决方案
为什么有的模型价格为 0 或无法参与比较？站点明确提供零价时，该模型可能确实免费；价格数据不完整时，页面会将其标为不可比较，而不会当作免费报价。
跨站比对时，汇率是怎么计算的？插件内置了 1 USD = 7.3 CNY 的固定汇率（参考 New API 约定），主要用于统一比对基准。
为什么报价显示“未参与当前条件比较”？当前比较条件需要的某项价格（例如缓存读取价）没有由价格来源提供。你可以改用其他使用场景或调整占比，也可以展开报价查看现有价格。
为什么验证结果显示“未知”？请检查你的 API Key 是否有权限调用该模型，或者站点当前是否触发了频率限制。
